What that row means

Drop the password, lose the alarm

Two redis instances, one password apart, behind the same NetworkPolicy. Delete it in front of both and only one loses the data — but the same change also erases the signal. The detection was the failed login. Where nothing authenticates, nothing fails, and nothing is logged.

How it works

Six steps of chaos

Always in this order. The control goes back even if you interrupt it.

01

steady state

Abort if the precondition is already broken.

02

fault

Disable one security control.

03

probe

Run the attack it was meant to stop.

04

observe

Did anything catch it, and when.

05

restore

Always. Interrupted runs too.

06

verify

Recovery measured, not assumed.

Install

Running in a minute

Go 1.26+ and a cluster you are allowed to break, on a CNI that enforces NetworkPolicy — Calico, Cilium, kube-router or Weave.
