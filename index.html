What that row means

Drop the password, lose the alarm

Two redis instances, one password apart, behind the same NetworkPolicy. Delete it in front of both and only one loses the data — but the same change also erases the signal. The detection was the failed login. Where nothing authenticates, nothing fails, and nothing is logged.

An experiment, not a script

Six steps, always in this order. The control goes back even if you interrupt it.

Install

One binary. No agents, no CRDs

Go 1.26+ and a kubeconfig for a cluster you are allowed to break.

$ go install github.com/Thran34/secha/cmd/secha@latest
$ secha demo   # builds its own target, measures, deletes it
$ secha run experiment.yaml --dry-run   # nothing is touched
